# 🏥 의료기관 원무과 월간통계 보고서 시스템
### 제작: 주식회사 메디엄 조정윤

---

## 📌 프로그램 개요

의료기관 원무과의 월간 접수현황 데이터를 업로드하면  
자동으로 이번달/저번달 **비교 분석 보고서**를 웹 화면에 생성합니다.

---

## 🗂️ 지원 파일 형식

| 파일 종류 | 필수 여부 | 설명 |
|-----------|-----------|------|
| 이번달 접수현황 (xlsx) | ✅ 필수 | 수진자, 접수일자, 환자유형, 초/재, 진료의사, 주소, 내원경로, 주상병 포함 |
| 저번달 접수현황 (xlsx) | ✅ 필수 (비교) | 동일 형식 |
| 월간결산 (xlsx) | ⬜ 선택 | 기존 원무과 결산 파일 |

---

## 📊 분석 항목

1. **핵심 요약 (KPI)**  
   - 총 내원환자수, 신환수, 재진수, 자보환자수  
   - 전월 대비 증감 수치 및 비율 자동 계산

2. **환자유형 분석**  
   - 건강보험 / 자보 / 의료급여 / 일반  
   - 도넛 파이차트 + 전월 비교 막대그래프 + 비율표

3. **진료의사(과)별 현황**  
   - 한방1·2·3·5과, 양방6·7과 등  
   - 전월 비교 + 환자유형 교차 분석

4. **초·재진 현황**  
   - 신규 / 초진 / 재진 / 미산정  
   - 진료의사별 히트맵 교차분석

5. **내원경로 분석**  
   - 간판 / 온라인광고 / 지인소개 / 오프라인광고 / 협약 / 기타  
   - 전월 비교 + 환자유형 교차 분석

6. **지역 분포**  
   - 주소 → 시/군/구, 읍/면/동 자동 추출  
   - 상위 지역 막대그래프

7. **주상병 분석**  
   - 다빈도 상병 Top N (사이드바에서 조절 가능)  
   - 카테고리 분류 (외상/염좌, 근골격계, 신경계 등)  
   - 전월 비교

8. **일별 내원 추이**  
   - 일별 환자수 꺾은선 그래프  
   - 요일별 환자수 분석

9. **원본 데이터 조회**  
   - 이번달/저번달 원본 데이터 테이블

## 🚀 실행 방법

### 1단계: Python 환경 준비 (Python 3.9 이상 권장)

```bash
# 가상환경 생성 (선택, 권장)
python -m venv venv

# Windows
venv\Scripts\activate

# Mac / Linux
source venv/bin/activate
```

### 2단계: 라이브러리 설치

```bash
pip install -r requirements.txt
```

### 3단계: 앱 실행

```bash
streamlit run hospital_report.py
```

### 4단계: 브라우저 접속

실행 후 자동으로 브라우저가 열리거나,  
주소창에 `http://localhost:8501` 입력

## ⚙️ 주요 기능

- ✅ 엑셀 날짜 숫자(시리얼) 자동 변환
- ✅ 내원경로 자동 정규화 (지인소개 → 지인소개, 지인소개(원무과XXX) → 지인소개 등)
- ✅ 주소에서 시/군/구, 읍/면/동 자동 추출
- ✅ 주상병 코드 카테고리 자동 분류 (S: 외상, M: 근골격계 등)
- ✅ 전월 대비 증감 자동 계산 및 색상 표시
- ✅ 다중 시트 자동 병합
